# Автомобильная книга перемен

## Навигация по документации

| Документ | За что отвечает |
|---|---|
| [Спецификация](automotive_book_of_changes_spec.md) | Что должно делать приложение: правила, утверждённые вопросы, поведение и критерии приёмки. Не зависит от среды разработки. |
| [UI_SPEC.md](UI_SPEC.md) | Как выглядит приложение: дизайн-система, типографика, цвета, композиция, компоненты, визуальные состояния и адаптивность. |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Как устроена текущая реализация: стек, архитектура, форматы, ресурсы, запуск, проверки и размещение. |
| [TODOs.md](TODOs.md) | В каком порядке выполняются работы, что предъявляется на каждом этапе и какие майлстоуны приняты пользователем. |
| [data/README.md](data/README.md) | Какие подготовленные данные существуют, их поля, ключи и связи. |

При изменении проекта обновляется документ, отвечающий за соответствующую часть. Пользовательское поведение задаётся спецификацией, внешний вид — UI_SPEC.md, способы реализации — архитектурой, порядок работ — TODOs. README служит навигацией по проекту.

## Подготовленный контент

- `src/` и `index.html` — приложение полного интервью M2: 12–24 вопроса и вычисленный результат; принято пользователем 21 октября 2026.
- `Start-App.cmd` — запуск приложения; альтернативно `npm.cmd run dev` из терминала проекта. Проверки: `npm.cmd test`, `npm.cmd run check:ui`, `npm.cmd run build`; браузерные сценарии при работающем сервере — `npm.cmd run test:browser`.
- `data/` — актуальные JSON-данные фиксированной матрицы, 64 автомобилей, утверждённых текстов и фотографий. [Описание данных](data/README.md).
- `assets/images/cars/` — 64 локальные фотографии, используемые галереей и каталогом.
- `avtomobilnaya_kniga_peremen_gallery.html` и `gallery.js` — рабочая галерея для просмотра подготовленного контента.
- `serve-gallery.cjs` и `Start-Gallery.cmd` — запуск рабочей галереи.

Галерея — инструмент подготовки контента. Она не является реализацией приложения для интервью.

Запуск галереи и будущего приложения описывается в [ARCHITECTURE.md](ARCHITECTURE.md#запуск-и-проверки). Текущее состояние этапов — в [TODOs.md](TODOs.md#текущее-состояние).

## Архив

В `archive/` сохранены начальный бриф, промежуточные заметки, история редактирования и прежние версии галереи. Эти материалы не являются источником требований или актуального каталога. Обращаться к ним следует только для отдельной работы с историей проекта.
